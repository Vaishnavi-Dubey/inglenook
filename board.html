AI engine

How the entities and connections get extracted

Cascades through free models (qwen3-next → gpt-oss → gemma-4). Best quality, requires an OpenRouter API key set in Reading Vault settings.

Runs a real LLM on your machine — private, offline, no key. One-time setup:
brew install ollama && ollama pull llama3.2:3b
Then start Ollama with CORS enabled: OLLAMA_ORIGINS=* ollama serve

100% offline. Uses compromise.js for named-entity recognition (people, places, orgs) and derives connections from sentence co-occurrence. Fast and free, but no LLM-quality descriptions.

Runs a real LLM entirely in your browser via WebGPU. Requires Chrome/Edge/Arc on desktop.
Heads up: first run downloads ~700 MB (1B model) or ~1.7 GB (3B), then compiles shaders. Even after that, in-browser generation is much slower than a cloud API — expect ~30–90 seconds per chapter on a typical laptop. Need instant results? Switch to Offline mode.
